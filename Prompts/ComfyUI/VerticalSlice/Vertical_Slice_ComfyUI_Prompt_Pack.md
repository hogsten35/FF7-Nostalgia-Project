# Echoes — Vertical Slice ComfyUI Prompt Pack

These prompts are written for **concept-to-3D workflow** use. The goal is to generate **clean, readable, model-friendly reference images** for ComfyUI image generation and later image-to-3D / manual modeling.

## General ComfyUI Guidance

Use these global guidelines with most prompts:

- full body visible when generating characters
- neutral stance or T-pose where specified
- clean silhouette
- plain or minimal background
- no dramatic foreshortening
- no text or logos in image
- clear costume layering and hard-surface detail
- readable proportions
- front / side / back turnaround when requested
- studio lighting or neutral presentation lighting
- realistic game concept art style, late-90s/early-2000s JRPG cinematic feel, but original IP

### Recommended negative prompt (general)
`low detail, blurry, extra limbs, duplicate limbs, missing fingers, cropped, cut off feet, cut off hands, bad anatomy, messy background, heavy motion blur, exaggerated fisheye perspective, unreadable design, text, watermark, logo, UI, deformed weapon, asymmetrical mistakes`
